# Nimbat Race Mod

Species mod for Humanoid Alien Races, based on Dean Dodrill's Elysian Tail settings.
Created by gamerfox.

Work in progress; if you're not developing, installing's probably not for you. Steam Workshop link when it's done(tm).

## Feature goals
 - Hovers, ignoring terrain speed modifiers if both wings are intact.
 - Unique background stories.
 - Nimbat colony faction (?)
 - Maybe integration with magic mods?
